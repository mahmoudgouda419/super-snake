## Getting Started
1. Clone the repo.
2. Open `index.html` in your browser.
3. Press any key to start.
4. Use the arrow keys to control the snake.
5. Press Space to pause the game.

[Play SUPER-SNAKE Online](https://mahmoudgouda419.github.io/super-snake/)
